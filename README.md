# Κρεμάλα 🎯


Ελληνικό παιχνίδι λέξεων για κινητά, tablets και υπολογιστές, εγκαταστάσιμο ως PWA.

- **Κλασική Κρεμάλα**: ένας παίκτης, παίζει και **offline**
- **Μονομαχία**: 2–8 παίκτες, ανεξάρτητα ταμπλό, κατάταξη από τον server, online ή με bots
- **Συνεργατική Κρεμάλα**: κοινή λέξη, κοινές προσπάθειες, κοινό χρονόμετρο και σκορ, online ή με bots
- **Bots** (Εύκολο/Μέτριο/Δύσκολο) με ελληνικά ονόματα, που **δεν βλέπουν τη λέξη**
- **Online ιδιωτικά δωμάτια**: κωδικός 5 χαρακτήρων, σύνδεσμος πρόσκλησης, επανασύνδεση
- Ελληνικό λεξικό με **550 λέξεις σε 14 κατηγορίες** και 3 επίπεδα δυσκολίας

## Γρήγορη εκκίνηση

Απαιτείται Node.js 20 ή νεότερο.

```bash
git clone https://github.com/lvarnavas/greek-games-kremala.git
cd greek-games-kremala
npm install
npm run dev        # server στο :3001 + client (Vite) στο :5173
```

Άνοιξε το http://localhost:5173. Για δοκιμή από κινητό στο ίδιο δίκτυο, άνοιξε το `http://<IP-υπολογιστή>:5173`.

| Script | Τι κάνει |
| --- | --- |
| `npm run dev` | Server (tsx watch) και client (Vite) μαζί |
| `npm test` | Όλα τα unit και integration tests (Vitest) |
| `npm run typecheck` | Έλεγχος τύπων TypeScript σε shared, server, client |
| `npm run build` | Build του client (με PWA/service worker) και bundle του server |
| `npm start` | Παραγωγή: ο server σερβίρει το API και το `client/dist` |
| `npm run dict:build` | Ξαναδημιουργεί το `words.json` από το `words.source.json` |
| `npm run icons` | Ξαναδημιουργεί τα PNG εικονίδια της PWA |

## Deployment

Το απλούστερο: μία υπηρεσία Node που σερβίρει μαζί τον client και τον Socket.IO server.

```bash
npm ci
npm run build
PORT=8080 npm start
```

- Λειτουργεί σε Render, Railway, Fly.io, ένα VPS κ.λπ. Ο host πρέπει να υποστηρίζει **WebSockets**.
- Η PWA (service worker, εγκατάσταση) απαιτεί **HTTPS** στην παραγωγή (το `localhost` εξαιρείται).
- Health check: `GET /health`.
- Αν ο client φιλοξενείται χωριστά (π.χ. σε CDN), όρισε `VITE_SERVER_URL` κατά το build του client και `CLIENT_ORIGIN` στον server. Δες το `.env.example`.
- Τα δωμάτια ζουν στη μνήμη μίας διεργασίας. Για πολλές διεργασίες θα χρειαζόταν sticky sessions και κοινή αποθήκευση (π.χ. Redis adapter), που δεν περιλαμβάνεται.

## Αρχιτεκτονική

```
shared/   Κοινό game engine (TypeScript, χωρίς εξαρτήσεις): χρησιμοποιείται ΑΥΤΟΥΣΙΟ από client και server
  data/words.source.json   λεξικό-πηγή (κατηγορίες → λέξεις)
  data/words.json          παραγόμενο λεξικό με id, κατηγορία, δυσκολία
  src/normalize.ts         κανονικοποίηση (τόνοι, διαλυτικά, τελικό ς, λατινικά πλήκτρα)
  src/board.ts             ένα «ταμπλό» = μία λέξη: μαντεψιά, λάθη, νίκη/ήττα, χρόνος, υποδείξεις, δημόσια προβολή
  src/scoring.ts           βαθμολογία, ποινές, μπόνους ταχύτητας
  src/ranking.ts           ντετερμινιστική κατάταξη μονομαχίας και συνόλων
  src/dictionary.ts        επιλογή λέξεων, ισοδύναμες λέξεις
  src/bots.ts              στρατηγικές bots (μόνο από τη δημόσια προβολή)
  src/match.ts             Game/Round: γύροι, λειτουργίες, stepGame (χρόνος + bots), getView (φιλτραρισμένη προβολή)
  src/protocol.ts          γεγονότα Socket.IO και ελληνικά μηνύματα σφαλμάτων
server/   Express + Socket.IO
  src/rooms.ts             RoomManager (ανεξάρτητο από sockets → testable): δωμάτια, host, επανασύνδεση, rate limit
  src/app.ts               σύνδεση Socket.IO, αποστολή προβολής ανά παίκτη, στατικά αρχεία
client/   React + Vite + Tailwind + vite-plugin-pwa
  src/lib/localGame.ts     τοπικός controller (Κλασική/bots) πάνω στο ίδιο engine, αποθήκευση σε IndexedDB
  src/lib/online.ts        client Socket.IO, επανασύνδεση με token, συγχρονισμός ρολογιού
  src/lib/db.ts            IndexedDB: πρόοδος, ιστορικό, στατιστικά, προτιμήσεις
  src/screens/GameScreen   ΜΙΑ οθόνη παιχνιδιού για όλες τις λειτουργίες (local και online)
```

**Ροή δεδομένων.** Η πλήρης κατάσταση (`Game`, που περιέχει την κρυφή λέξη) υπάρχει μόνο εκεί που «τρέχει» το παιχνίδι: στον server για online, στον browser για solo/bots. Η οθόνη λαμβάνει πάντα ένα `GameView` από τη `getView(game, viewerId)`, που:

- δεν περιέχει τη λέξη όσο ο γύρος παίζεται (μόνο μάσκα με `null` στις κρυφές θέσεις),
- στη Μονομαχία δείχνει για τους αντιπάλους μόνο πλήθος αποκαλυμμένων γραμμάτων, λάθη και κατάσταση (τα γράμματα μόνο με τη ρύθμιση «Και γράμματα»),
- δεν περιλαμβάνει τις μαντεψιές των αντιπάλων στο ημερολόγιο ενεργειών.

Έτσι η online και η τοπική λειτουργία χρησιμοποιούν την ίδια λογική και το ίδιο UI.

### Μοντέλο δεδομένων (`shared/src/types.ts`)

- **Game**: `id, mode, status, settings, players, currentRound, roundHistory, createdAt, updatedAt` (+ `teamScore, hostId, bots, usedWordIds`)
- **Round**: `id, mode, wordId, category, guessedLetters, correctLetters, incorrectLetters, mistakes, maxMistakes, startedAt, deadline, status, winnerId, scoreByPlayer, teamScore` (+ `boards, participants, ranking, breakdown, participation, log`)
- **Player**: `id, displayName, score, wins, losses, streak, connectionStatus, lastSeenAt` (+ `isBot, botLevel, joinedAt`)
- **Settings**: `gameMode, categories, difficulty, maxMistakes, roundDuration, totalRounds, targetScore, hintsEnabled, hintPenalties, timerEnabled, soundEnabled, theme, reducedMotion, showOpponentProgress` (+ `maxHintsPerRound, speedBonusEnabled, wordMode, showGuessAuthor, coopScoring, botsUseHints`)
- **Board**: η κατάσταση μίας λέξης. Στη **Συνεργατική** υπάρχει **ένα κοινό** ταμπλό (`__team__`). Στη **Μονομαχία/Κλασική** υπάρχει **ένα ανά παίκτη**, ακόμη και με κοινή λέξη.

Στη Μονομαχία, τα συνοπτικά πεδία του `Round` (`guessedLetters` κ.λπ.) είναι η ένωση όλων των ταμπλό και το `mistakes` το άθροισμά τους. Οι λεπτομέρειες ανά παίκτη βρίσκονται στο `boards`.

## Κανόνες και βαθμολογία

- Προεπιλογές: 6 λάθη, 120″ ανά γύρο, 10 γύροι, υποδείξεις ενεργές.
- Νίκη: 0 λάθη = 100, 1 = 80, 2 = 60, 3 = 40, 4+ = 20 πόντοι. Ήττα = 0.
- Υποδείξεις (έως 2/γύρο): **αποκάλυψη γράμματος** −25, **αφαίρεση 3 λάθος γραμμάτων** −10. Το σκορ δεν πέφτει κάτω από 0.
- Μπόνους ταχύτητας έως +20 (ανενεργό από προεπιλογή): `20 × χρόνος που απέμεινε / διάρκεια`.
- **Κατάταξη Μονομαχίας** (server): νίκη → πόντοι → λιγότερα λάθη → λιγότερος χρόνος → ισοπαλία (ίδια θέση, χωρίς νικητή γύρου). Οι ισόβαθμοι εμφανίζονται με σταθερή σειρά (κατά id).
- **Τελική κατάταξη**: συνολικοί πόντοι → νίκες → λάθη → χρόνος.
- **Συνεργατική**: κοινοί πόντοι ομάδας ανά γύρο. Η συμμετοχή καταγράφεται ως στατιστικό. Με «Κοινή + ατομικοί πόντοι» κάθε παίκτης παίρνει επιπλέον +10 ανά σωστό γράμμα που πρότεινε.

## Online δωμάτια

- Κωδικός 5 χαρακτήρων (χωρίς 0/O/1/I/L), σύνδεσμος `/?room=CODE`, 2–8 παίκτες (και bots).
- Ο οικοδεσπότης ορίζει λειτουργία και ρυθμίσεις. **Κλειδώνουν στην έναρξη** και δεν αλλάζουν στη μέση του παιχνιδιού.
- Online «Κλασική» = κάθε παίκτης παίζει ανεξάρτητα με **δική του** λέξη.
- **Επανασύνδεση**: ο client κρατά ένα μυστικό token. Μετά από αποσύνδεση ή ανανέωση, επιστρέφει στον ίδιο παίκτη με όλη την πρόοδο. Οι αποσυνδεδεμένοι δεν μπλοκάρουν τον γύρο.
- **Οικοδεσπότης**: αν αποχωρήσει, ο ρόλος περνά αμέσως στον αρχαιότερο συνδεδεμένο. Αν αποσυνδεθεί, περνά μετά από 15″.
- Αν ο οικοδεσπότης δεν πατήσει «Επόμενος γύρος», ο γύρος ξεκινά αυτόματα σε 20″.
- **Ασφάλεια**: όλες οι ενέργειες επικυρώνονται στον server. Υπάρχει rate limit (token bucket, 8 ριπή / 4 ανά δευτερόλεπτο) και επικύρωση όλων των εισόδων. Οι ενέργειες επεξεργάζονται σειριακά: σε ταυτόχρονη επιλογή του ίδιου γράμματος γίνεται δεκτή μόνο η πρώτη.
- Τα άδεια δωμάτια διαγράφονται μετά από 10′.

## Bots

| Επίπεδο | Στρατηγική | Αντίδραση |
| --- | --- | --- |
| Εύκολο | τυχαία γράμματα σταθμισμένα με τη συχνότητα | 2,8–5″ |
| Μέτριο | σειρά συχνότητας με τυχαιότητα, μερικές φορές χρήση λεξικού | 1,7–3,2″ |
| Δύσκολο | φιλτράρει το λεξικό με βάση τη μάσκα, την κατηγορία και τα λάθη και διαλέγει το πιθανότερο γράμμα | 1–2″ |

Τα bots λαμβάνουν **μόνο** το δημόσιο `BoardView`, ποτέ τη λέξη. Το test «η απόφαση εξαρτάται μόνο από τη δημόσια προβολή» ελέγχει ότι δύο διαφορετικές μυστικές λέξεις με ίδια ορατή κατάσταση οδηγούν στην ίδια επιλογή. Υποδείξεις χρησιμοποιούν μόνο αν το επιτρέπουν οι ρυθμίσεις (Μέτριο/Δύσκολο, στην τελευταία ευκαιρία). Bots μπορούν να προστεθούν και σε online δωμάτια, όπου τρέχουν στον server.

## PWA και offline

- Το `vite-plugin-pwa` (Workbox) προ-αποθηκεύει όλα τα αρχεία, μαζί με το λεξικό που είναι ενσωματωμένο στο bundle.
- Μετά την πρώτη επίσκεψη, η Κλασική και τα bots παίζουν **χωρίς σύνδεση**.
- Οι λειτουργίες online επισημαίνονται ως «Απαιτεί σύνδεση» όταν η συσκευή είναι offline.
- Η πρόοδος solo αποθηκεύεται σε **IndexedDB** μετά από κάθε ενέργεια. Από την αρχική οθόνη υπάρχει «Συνέχεια παιχνιδιού», και ο χρόνος παγώνει όσο η εφαρμογή ήταν κλειστή.
- Αυτόματη παύση όταν η εφαρμογή πάει στο παρασκήνιο. Υπάρχει και κουμπί παύσης.

## Προσβασιμότητα

Ελληνικό `lang`, ετικέτες ARIA σε πλήκτρα και σχέδιο, ανακοινώσεις `aria-live` για σωστό/λάθος/τέλος γύρου, πλήρης χρήση με φυσικό πληκτρολόγιο (ελληνικό ή λατινικό), στόχοι αφής ≥44px, σκοτεινό θέμα, «μειωμένη κίνηση» (και σεβασμός του `prefers-reduced-motion`), αλφαβητική ή «υπολογιστή» διάταξη πληκτρολογίου.

## Tests

`npm test` τρέχει 100 tests σε 12 αρχεία (ο έλεγχος του service worker παραλείπεται αν δεν έχει γίνει `npm run build`):

- **shared**: κανονικοποίηση, αποκάλυψη όλων των εμφανίσεων, αποτροπή επαναλήψεων, λάθη, νίκη/ήττα, βαθμολογία/ποινές/μπόνους, λήξη χρόνου, μηδενισμός/επόμενος γύρος/επανεκκίνηση, Μονομαχία με 2 και 4 παίκτες, ισοβαθμίες, απόκρυψη λέξης, Συνεργατική με κοινές προσπάθειες, ταυτόχρονη επιλογή, bots, εγκυρότητα λεξικού
- **server**: RoomManager (host, όρια, κλείδωμα λειτουργίας, επανασύνδεση, rate limit, αυτόματος γύρος, μεταβίβαση host) και **integration** με πραγματικό Socket.IO και πολλούς clients (συγχρονισμός, απόκρυψη λέξης στα πραγματικά μηνύματα, διπλό γράμμα, επανασύνδεση, πολλαπλά sockets)
- **client**: IndexedDB (αποθήκευση/ανάκτηση προόδου, στατιστικά, fallback), τοπικό παιχνίδι **offline** (με `fetch` μπλοκαρισμένο και `navigator.onLine=false`), bots, παύση, components, PWA manifest/service worker

## Αποφάσεις σε ασάφειες

- **Υποδείξεις**: δύο τύποι (αποκάλυψη −25, αφαίρεση 3 γραμμάτων −10), έως 2 ανά γύρο.
- **Λέξη μετά από ήττα**: στη Μονομαχία η λέξη αποκαλύπτεται σε όλους **μόνο** στο τέλος του γύρου, ακόμη και σε όσους τελείωσαν νωρίτερα.
- **Νίκες/ήττες παίκτη** στη Μονομαχία μετράνε μόνο αν ήταν ο μοναδικός νικητής του γύρου. Στην Κλασική και τη Συνεργατική μετράει η εύρεση της λέξης.
- **Παίκτες που μπαίνουν μετά την έναρξη**: δεν επιτρέπεται, εκτός αν πρόκειται για επανασύνδεση με token.
- **Ίδια συσκευή, δύο καρτέλες**: η συνεδρία κρατιέται ανά καρτέλα (sessionStorage) με εφεδρεία στο localStorage. Έτσι, ένας σύνδεσμος πρόσκλησης στον ίδιο browser όπου ήδη παίζεις σε επανασυνδέει ως τον ίδιο παίκτη.
- **Δυσκολία λέξεων**: υπολογίζεται αυτόματα (`shared/src/difficulty.ts`) από τη συχνότητα των μοναδικών γραμμάτων και το μήκος. Τα όρια χωρίζουν το λεξικό περίπου σε τρίτα.
- **Ήχοι**: παράγονται με Web Audio, χωρίς αρχεία, άρα λειτουργούν και offline.

## Προσθήκη λέξεων

Επεξεργάσου το `shared/data/words.source.json` και τρέξε `npm run dict:build`. Τα tests ελέγχουν ότι:

- κάθε λέξη έχει μόνο ελληνικά γράμματα και μήκος 4–15,
- δεν υπάρχουν διπλές λέξεις,
- κάθε κατηγορία έχει τουλάχιστον 30 λέξεις,
- το `words.json` είναι συγχρονισμένο με την πηγή.
